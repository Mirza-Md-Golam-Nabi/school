## ১৩.১ পরিচিতি

স্কুলের মৌলিক তথ্য, ডকুমেন্টের চেহারা, গ্রেডের নিয়ম ও বাইরের অ্যাপের সংযোগ এখান থেকে ঠিক করা হয়। নতুন স্কুল সেটআপের সময় **সবার আগে** এগুলো ঠিক করুন।

**মেনু:** বাম পাশের **School Settings** গ্রুপ:

| মেনু | কাজ |
|---|---|
| School Settings | স্কুলের তথ্য, ছুটির দিন, শিক্ষাবর্ষ, লোগো-স্বাক্ষর, রেজাল্ট, ডকুমেন্ট |
| Grading Scale | গ্রেড ও গ্রেড পয়েন্ট |
| Question Bank | প্রশ্নব্যাংক অ্যাপের সাথে সংযোগ |

## ১৩.২ School Settings

**মেনু:** School Settings → School Settings

সব ঘর পূরণ করে নিচে **Save Settings** চাপুন।

`[স্ক্রিনশট: School Settings]`

### ক. General — সাধারণ

| ঘর | বিবরণ |
|---|---|
| School Name | স্কুলের নাম (ইংরেজি) — বাধ্যতামূলক |
| School Name (বাংলা) | বাংলা ডকুমেন্টে ছাপা হয় (যেমন সিট প্ল্যান)। খালি রাখলে ইংরেজি নাম। |
| School Code | ৩ সংখ্যার কোড — ৮ সংখ্যার Student ID-র প্রথম ৩ সংখ্যা (যেমন ১০১ → ১০১০০০২৫) |

**সতর্কতা:** School Code বদলালে শুধু **নতুন** শিক্ষার্থীর ID-তে প্রভাব পড়ে। আগে তৈরি ID বদলায় না। তাই প্রথম শিক্ষার্থী ভর্তির আগেই ঠিক করে নিন।

### খ. Working Days — সাপ্তাহিক ছুটি

**Weekend Days** — যে দিনগুলো সাপ্তাহিক ছুটি (যেমন শুক্রবার, শনিবার)। এই দিনগুলো উপস্থিতি, ছুটির আবেদন ও রিপোর্টে কার্যদিবস হিসেবে গোনা হয় না।

সরকারি ছুটির জন্য দেখুন [HR & Staff → Public Holidays](08-hr-and-staff.md)।

### গ. Academic Session — শিক্ষাবর্ষ

**College Session Start Month** — কলেজের (একাদশ-দ্বাদশ) শিক্ষাবর্ষ কোন মাসে শুরু হয় (ডিফল্ট জুলাই → সেশন ২০২৬-২৭)। স্কুলের বাকি সব ক্লাসের শিক্ষাবর্ষ জানুয়ারি থেকে ডিসেম্বর।

### ঘ. Branding — লোগো, সিল ও স্বাক্ষর

অ্যাডমিট কার্ড, মার্কশিট, আইডি কার্ড ইত্যাদি সব ডকুমেন্টে ব্যবহৃত হয়।

| ঘর | বিবরণ |
|---|---|
| School Logo | স্কুলের লোগো (হোম পেজেও দেখায়) |
| School Seal / Stamp | স্কুলের সিল |
| Head Signatory Title (English) | প্রধানের পদবি, যেমন Headmaster, Principal — স্বাক্ষরের নিচে ছাপা হয় |
| Head Signatory Title (বাংলা) | যেমন প্রধান শিক্ষক, অধ্যক্ষ |
| Head Signatory's Signature | প্রধানের স্বাক্ষরের ছবি |
| School Address | ঠিকানা (ইংরেজি) |
| School Address (বাংলা) | বাংলা ডকুমেন্টের জন্য |
| EIIN Number | ডকুমেন্টে স্কুলের নামের নিচে "EIIN: …" হিসেবে ছাপা হয় |
| Established Year | প্রতিষ্ঠার সাল |

**টিপস:** স্বাক্ষর ও সিলের ছবি সাদা বা স্বচ্ছ ব্যাকগ্রাউন্ডে দিন, যাতে ডকুমেন্টে পরিষ্কার দেখায়।

### ঙ. Result — রেজাল্ট

**Result Full Marks** — Result Rule-এ পূর্ণমান না দিলে রেজাল্ট এই মানে তৈরি হয় (ডিফল্ট ১০০)।

### চ. Merged Subjects — মার্জের ডিফল্ট নিয়ম

দুইটা বিষয় মিলে একটা বিষয় (যেমন বাংলা ১ম + ২য় পত্র = বাংলা) — সব মার্জের ডিফল্ট নিয়ম। কোনো মার্জে চাইলে ক্লাস বা পরীক্ষা থেকে আলাদা নিয়ম দেওয়া যায়।

| ঘর | অপশন |
|---|---|
| Pass Rule | দুই পত্রের যৌথ নম্বরে পাস / প্রতিটা পত্রে আলাদা পাস |
| MCQ / Written / Practical Pass | যৌথ / প্রতিটা পত্রে আলাদা (শুধু যৌথ পাসের নিয়মে খাটে) |
| Absent In One Paper | বিষয়ে ফেল / অনুপস্থিত পত্রে ০ ধরে হিসাব |
| Rounding | দশমিক / কাছের পূর্ণসংখ্যা / উপরে / নিচে |

বিস্তারিত: [Academic Structure → বিষয় মার্জ](01-academic-structure.md)।

### ছ. Admit Card

| ঘর | বিবরণ |
|---|---|
| Footer Text | কার্ডের নিচে ছাপা লেখা (যেমন "পরীক্ষার হলে মোবাইল নিষিদ্ধ") |
| Show Verification QR Code | কার্ডে যাচাইয়ের QR কোড |

### জ. Marksheet

| ঘর | বিবরণ |
|---|---|
| Show School Logo | মার্কশিটে লোগো |
| Show Watermark | পেছনে জলছাপ |
| Watermark Text | জলছাপের লেখা |
| Footer Text | নিচের লেখা |
| Show Verification QR Code | যাচাইয়ের QR — জাল মার্কশিট ধরা পড়ে |

### ঝ. Fee Payment Slip

**Show Verification QR Code** — রসিদে QR, যাতে জাল বা ঘষামাজা করা রসিদ ধরা পড়ে।

**মনে রাখুন:** ডকুমেন্টের সেটিং বদলালে তা শুধু **নতুন করে তৈরি করা** ডকুমেন্টে প্রযোজ্য। আগের ডকুমেন্ট আবার Generate করুন।

## ১৩.৩ Grading Scale — গ্রেডিং স্কেল

**মেনু:** School Settings → Grading Scale

কত নম্বরে কোন গ্রেড ও কত পয়েন্ট, তা এখান থেকে ঠিক হয়।

### ডিফল্ট স্কেল

| Letter Grade | Min Mark | Max Mark | Grade Point |
|---|---|---|---|
| A+ | ৮০ | ১০০ | ৫.০০ |
| A | ৭০ | ৭৯ | ৪.০০ |
| A- | ৬০ | ৬৯ | ৩.৫০ |
| B | ৫০ | ৫৯ | ৩.০০ |
| C | ৪০ | ৪৯ | ২.০০ |
| D | ৩৩ | ৩৯ | ১.০০ |
| F | ০ | ৩২ | ০.০০ |

### পরিবর্তন করা

**ধাপ ১:** প্রতিটা সারিতে **Letter Grade**, **Min Mark**, **Max Mark**, **Grade Point** ও **Color** (রং) ঠিক করুন।

**ধাপ ২:** নতুন গ্রেড যোগ করতে নিচের যোগ বাটন, মুছতে সারির মুছে ফেলার বাটন।

**ধাপ ৩:** **Save Grading Scale** চাপুন।

**মনে রাখুন:**

- **গ্রেড ঠিক হয় শুধু Min Mark দিয়ে** — সবচেয়ে বড় Min Mark থেকে নিচে নেমে, প্রথম যেটার Min Mark-এর সমান বা বেশি নম্বর আছে সেই গ্রেড। তাই ৭৯.৫ নম্বর পেলে গ্রেড A (কারণ ৭৯.৫ ≥ ৭০)। Max Mark শুধু দেখানোর জন্য।
- অন্তত একটা গ্রেড থাকতে হবে। কোনো সারিতে Min Mark, Max Mark-এর চেয়ে বড় হলে সেভ হবে না।
- স্কেল বদলালে আবার **Calculate Rankings** চালান এবং মার্কশিট আবার Generate করুন।

## ১৩.৪ Question Bank — প্রশ্নব্যাংক সংযোগ

**মেনু:** School Settings → Question Bank

স্কুল যদি আলাদা **Question Bank** (প্রশ্নব্যাংক) অ্যাপ ব্যবহার করে, এখান থেকে সংযোগ করা যায়। সংযোগের পর:

- অ্যাডমিন ও শিক্ষক প্যানেলের মেনুতে **Question Bank** লিংক আসে (নতুন ট্যাবে খোলে)।
- প্রশ্নব্যাংকে নেওয়া অনলাইন MCQ পরীক্ষার নম্বর সরাসরি এই সফটওয়্যারের মার্কসে বসানো যায়।
- শিক্ষার্থী প্যানেলে **School Questions** পেজে স্কুলের নিজের প্রশ্ন (পরীক্ষা শেষ হওয়ার পর, উত্তরসহ) দেখা যায়।

### সংযোগ করা

**ধাপ ১:** প্রশ্নব্যাংক অ্যাপে স্কুলের অ্যাকাউন্টে গিয়ে "School software connection" অংশ থেকে তথ্য কপি করুন।

**ধাপ ২:** এখানে পূরণ করুন:

| ঘর | বিবরণ |
|---|---|
| Question Bank address | প্রশ্নব্যাংকের ঠিকানা |
| Connection code | সংযোগ কোড |
| Secret | গোপন কোড — শুধু প্রশ্নব্যাংকের পেজে দেখায়, কাউকে জানাবেন না |

**ধাপ ৩:** **Save and connect** চাপুন। সফল হলে লেখা আসবে *"Connected to the Question Bank as …"*। ব্যর্থ হলে *"Not connected"* সাথে কারণ।

**মনে রাখুন:** একবার Secret সেভ হলে আর দেখানো হয় না। পরে অন্য ঘর বদলাতে চাইলে Secret খালি রাখলে আগেরটাই থাকে।

## ১৩.৬ সাধারণ প্রশ্ন ও সমাধান

**প্রশ্ন: ডকুমেন্টে লোগো বা স্বাক্ষর আসছে না।**
উত্তর: Branding অংশে ছবি আপলোড করে Save করুন, তারপর ডকুমেন্ট আবার Generate করুন।

**প্রশ্ন: Student ID-র প্রথম ৩ সংখ্যা ভুল।**
উত্তর: School Code ঠিক করুন। তবে আগে তৈরি ID বদলাবে না — শুধু নতুনদের ঠিক হবে।

**প্রশ্ন: শুক্রবারেও উপস্থিতি Absent হচ্ছে।**
উত্তর: Weekend Days-এ শুক্রবার টিক দেওয়া নেই।

**প্রশ্ন: কলেজের সেশন ভুল দেখাচ্ছে।**
উত্তর: College Session Start Month ঠিক আছে কিনা এবং ক্লাসের Level = College কিনা দেখুন।
