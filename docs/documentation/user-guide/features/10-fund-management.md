## ১০.১ পরিচিতি

ফি ও বেতন ছাড়া স্কুলের অন্য সব আয় ও খরচ — যেমন বিদ্যুৎ বিল, মেরামত, অনুদান, বই বিক্রি — এখানে লেখা হয়। আর **Account Ledger**-এ ফি, বেতন ও অন্যান্য সব লেনদেন একসাথে দেখা যায়।

**মেনু:** বাম পাশের **Fund Management** গ্রুপ:

| মেনু | কাজ |
|---|---|
| Transaction Categories | আয়-ব্যয়ের খাত |
| Fund Transactions | ফি ও বেতন ছাড়া অন্যান্য আয় ও খরচ |
| Account Ledger | সব অ্যাকাউন্টের সব লেনদেন |

স্কুলের অ্যাকাউন্ট (Cash, Bank ইত্যাদি) তৈরি হয় **Fee & Finance → School Accounts** থেকে ([Fee & Finance](04-fee-and-finance.md))।

## ১০.২ কে ব্যবহার করতে পারেন

| অনুমতি | কাজ |
|---|---|
| View / Create / Edit / Delete transaction categories | খাত |
| View / Create / Edit / Delete fund transactions | আয়-ব্যয় এন্ট্রি |
| View account transactions | Account Ledger দেখা |

## ১০.৩ টাকার হিসাব কীভাবে চলে

```
                ┌── ফি আদায় (Fee Payment)        → আয়
School Account ─┼── বেতন প্রদান (Salary Payment)   → খরচ
                └── অন্যান্য (Fund Transaction)    → আয় বা খরচ
```

- প্রতিটা লেনদেন নিজে থেকে অ্যাকাউন্টের ব্যালেন্সে যোগ বা বিয়োগ হয়।
- লেনদেন সংশোধন করলে বা মুছলে ব্যালেন্সও নিজে থেকে ঠিক হয়।
- অ্যাকাউন্টের ব্যালেন্স হাতে বদলানো যায় না।

## ১০.৪ Transaction Categories — আয়-ব্যয়ের খাত

**মেনু:** Fund Management → Transaction Categories

**ধাপ ১:** **New transaction category** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বিবরণ |
|---|---|
| Name | খাতের নাম |
| Type | **Income** (আয়) অথবা **Expense** (খরচ) |
| Is Active | সক্রিয় / নিষ্ক্রিয় |

**ধাপ ৩:** **Create** চাপুন।

**উদাহরণ:**

| খাত | Type |
|---|---|
| বিদ্যুৎ বিল | Expense |
| মেরামত ও রক্ষণাবেক্ষণ | Expense |
| স্টেশনারি | Expense |
| অনুদান | Income |
| পুরনো বই বিক্রি | Income |

**ফিল্টার:** Type, Active Status।

## ১০.৫ Fund Transactions — অন্যান্য আয় ও খরচ

**মেনু:** Fund Management → Fund Transactions

**ধাপ ১:** **New fund transaction** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Category | হ্যাঁ | খাত। তালিকায় না থাকলে পাশের বাটন থেকে সেখানেই নতুন খাত তৈরি করা যায়। খাত বাছাই করলে **Type** (আয়/খরচ) নিজে থেকে দেখায়। |
| Account | হ্যাঁ | কোন অ্যাকাউন্ট থেকে খরচ বা কোন অ্যাকাউন্টে জমা |
| Title | হ্যাঁ | সংক্ষেপে কী, যেমন "নভেম্বর মাসের বিদ্যুৎ বিল" |
| Amount | হ্যাঁ | টাকা |
| Transaction Date | হ্যাঁ | তারিখ |
| Vendor / Donor Name | না | কাকে দিলেন বা কার থেকে পেলেন |
| Receipt / Bill (Optional) | না | বিল বা রসিদের ছবি / PDF |
| Description | না | বিস্তারিত |

**ধাপ ৩:** **Create** চাপুন। টাকা সাথে সাথে অ্যাকাউন্টের ব্যালেন্সে যোগ বা বিয়োগ হবে।

**মনে রাখুন:** আপলোড করা বিল বা রসিদ প্রাইভেট থাকে — শুধু অ্যাডমিন ও স্টাফ দেখতে পারেন।

### তালিকা

| কলাম | অর্থ |
|---|---|
| Title | শিরোনাম |
| Category, Type | খাত ও আয়/খরচ |
| Amount | টাকা |
| Account | অ্যাকাউন্ট |
| Vendor / Donor | পক্ষ |
| Transaction Date | তারিখ |
| Created By | কে এন্ট্রি দিয়েছেন |

**ফিল্টার:** Type, Category, Account।

## ১০.৬ Account Ledger — সব লেনদেনের খাতা

**মেনু:** Fund Management → Account Ledger

`[স্ক্রিনশট: Account Ledger]`

### উপরের সারসংক্ষেপ

নির্বাচিত তারিখের মধ্যে মোট **আয়** ও মোট **খরচ**। আয় বা খরচে ক্লিক করলে শুধু সেই ধরনের লেনদেন দেখায়। লেনদেনের ধরন অনুযায়ী ভাগ (ফি, বেতন, অন্যান্য) আলাদা করে দেখায়।

### তালিকা

| কলাম | অর্থ |
|---|---|
| Transaction Date | তারিখ |
| Account | অ্যাকাউন্ট |
| Type | Income / Expense |
| Source | **Fee Payment** (ফি আদায়), **Salary** (বেতন), **Other** (অন্যান্য) |
| Party | কার সাথে লেনদেন — শিক্ষার্থী, শিক্ষক/স্টাফ, বা বিক্রেতা/দাতা |
| Description | বিবরণ |
| Amount | টাকা |
| Created By | কে এন্ট্রি দিয়েছেন |

**ফিল্টার:** Account, Type, Source, Date Range (From – Until)।

**View** চাপলে লেনদেনের পুরো বিস্তারিত।

**মনে রাখুন:** Account Ledger শুধু দেখার জন্য। এখানে সরাসরি কিছু যোগ বা বদলানো যায় না। ফি, বেতন বা Fund Transaction সংশোধন করলে লেজার নিজে থেকে বদলায়।

## ১০.৭ সাধারণ প্রশ্ন ও সমাধান

**প্রশ্ন: অ্যাকাউন্টের ব্যালেন্স মিলছে না।**
উত্তর: Account Ledger-এ সেই অ্যাকাউন্ট দিয়ে ফিল্টার করে সব লেনদেন দেখুন। অনেক সময় কোনো ফি-এর ধরন ভুল অ্যাকাউন্টে যুক্ত থাকে — School Accounts দেখুন।

**প্রশ্ন: ফি আদায় হয়েছে কিন্তু লেজারে নেই।**
উত্তর: সেই ফি-এর ধরন কোনো অ্যাকাউন্টের সাথে যুক্ত নয়। Fee & Finance → School Accounts-এ যুক্ত করুন।

**প্রশ্ন: ভুল খরচ এন্ট্রি দিয়েছি।**
উত্তর: Fund Transactions-এ সেটি Edit বা Delete করুন। ব্যালেন্স নিজে থেকে ঠিক হবে।

**প্রশ্ন: বিলের ছবি খুলছে না।**
উত্তর: বিলের ফাইল শুধু অ্যাডমিন প্যানেলে লগইন করা অ্যাডমিন ও স্টাফ দেখতে পারেন।
