## ৬.১ পরিচিতি

এই অংশে স্কুলের SMS ব্যালেন্স, কোন কোন ঘটনায় অভিভাবকের কাছে SMS যাবে, SMS-এর লেখা এবং পাঠানো সব SMS-এর হিসাব রাখা হয়।

**মেনু:** বাম পাশের **SMS** গ্রুপ:

| মেনু | কাজ |
|---|---|
| SMS Settings | ব্যালেন্স দেখা, SMS চালু/বন্ধ, ভাষা, ঘটনা ও টেমপ্লেট |
| SMS Vendors | যে প্রতিষ্ঠানের মাধ্যমে SMS যায় (শুধু দেখার জন্য) |
| Recharge Requests | ব্যালেন্স রিচার্জের অনুরোধ |
| Balance History | ব্যালেন্সে কখন কত যোগ বা খরচ হয়েছে |
| SMS Logs | প্রতিটা পাঠানো SMS-এর বিস্তারিত |

## ৬.৩ SMS কীভাবে কাজ করে

- স্কুলের নিজস্ব একটা **SMS ব্যালেন্স** (টাকায়) থাকে। প্রতিটা SMS পাঠালে ব্যালেন্স থেকে খরচ কাটা হয়।
- ব্যালেন্স শেষ হলে সফটওয়্যার প্রদানকারীর কাছে **রিচার্জের অনুরোধ** পাঠাতে হয়। টাকা পরিশোধ নিশ্চিত হলে তারা ব্যালেন্স যোগ করে দেন।
- **সব অথবা কিছুই না:** একসাথে অনেক SMS পাঠানোর সময় (যেমন পুরো ক্লাসের রেজাল্ট) ব্যালেন্সে সবগুলোর খরচ না কুলালে **একটাও যায় না**। ফলে অর্ধেক অভিভাবক পেল, অর্ধেক পেল না — এমন হয় না।
- কোনো SMS পাঠাতে ব্যর্থ হলে তার খরচ ব্যালেন্সে ফেরত আসে।
- একই নম্বরে একই লেখা একবারই যায়।
- শিক্ষার্থী সংক্রান্ত সব SMS যায় **অভিভাবকের মোবাইল নম্বরে** (প্রোফাইলের Guardian's Phone)। সেটা না থাকলে শিক্ষার্থীর নিজের নম্বরে।

## ৬.৪ SMS-এর খরচ কীভাবে হিসাব হয়

একটা SMS-এ নির্দিষ্ট সংখ্যক অক্ষর ধরে। বেশি লম্বা হলে একাধিক "পার্ট" হয়, আর প্রতিটা পার্টের জন্য আলাদা খরচ।

| ভাষা | ১টি SMS-এ অক্ষর | একাধিক পার্ট হলে প্রতি পার্টে |
|---|---|---|
| ইংরেজি | ১৬০ | ১৫৩ |
| বাংলা | ৭০ | ৬৭ |

```
খরচ = পার্টের সংখ্যা × প্রতি SMS-এর চার্জ
```

**উদাহরণ:** প্রতি SMS ৳০.৩০ হলে ১০০ অক্ষরের বাংলা মেসেজ = ২ পার্ট = ৳০.৬০।

**টিপস:** ইংরেজিতে একটা SMS-এ দ্বিগুণের বেশি অক্ষর ধরে, তাই খরচ কমাতে SMS Language **English** রাখতে পারেন।

**মনে রাখুন:** প্রতি SMS-এর চার্জ সফটওয়্যার প্রদানকারী ঠিক করেন। স্কুল থেকে এটা বদলানো যায় না।

## ৬.৫ SMS Settings

**মেনু:** SMS → SMS Settings

`[স্ক্রিনশট: SMS Settings]`

### SMS Balance (শুধু দেখার জন্য)

| ঘর | অর্থ |
|---|---|
| Current Balance | বর্তমান ব্যালেন্স (৳) |
| SMS Available (approx.) | আনুমানিক কতটি SMS পাঠানো যাবে |
| Charge per SMS (৳) | প্রতি SMS-এর চার্জ |

উপরের **Recharge Request** বাটন চাপলে রিচার্জের পেজ খোলে।

### SMS Service

| ঘর | বিবরণ |
|---|---|
| Enable SMS | **বন্ধ থাকলে কোনো ঘটনাতেই SMS যাবে না।** |
| SMS Language | বাংলা অথবা English — ডিফল্ট টেমপ্লেট এই ভাষায় থাকে। ভাষা বদলালে আপনি নিজে বদলাননি এমন টেমপ্লেটগুলো নতুন ভাষায় বদলে যায়; নিজে লেখা টেমপ্লেট যেমন আছে তেমন থাকে। |

### Events & Templates

প্রতিটা ঘটনার জন্য একটা অংশ — **Send SMS for this event** চালু/বন্ধ এবং **Template** ([৬.৬](#৬৬-কোন-কোন-ঘটনায়-sms-যায়-events), [৬.৭](#৬৭-টেমপ্লেট-লেখা-ও-placeholder))।

সব ঠিক করে **Save Settings** চাপুন।

## ৬.৬ কোন কোন ঘটনায় SMS যায় (Events)

প্রতিটা ঘটনা আলাদা করে চালু বা বন্ধ করা যায়। ডিফল্টে বন্ধ থাকে।

| Event | কখন যায় |
|---|---|
| Attendance: Present | হাতে উপস্থিতি নেওয়ার সময় শিক্ষার্থী উপস্থিত হলে (শুধু আজকের তারিখের জন্য) |
| Attendance: Absent | শিক্ষার্থী অনুপস্থিত হলে — হাতে নেওয়া ও মেশিনের স্বয়ংক্রিয় অনুপস্থিতি দুটোতেই (শুধু আজকের তারিখের জন্য) |
| Device: School Entry | মেশিনে দিনের প্রথম স্পর্শে (স্কুলে প্রবেশ) |
| Device: School Exit | মেশিনে স্কুল থেকে বের হওয়ার স্পর্শে |
| Fee Generated | ফি ইনভয়েস তৈরি হলে — প্রতি শিক্ষার্থীর জন্য একটা SMS-এ মোট টাকা |
| Fee Payment Received | ফি পরিশোধ হলে — এক রসিদে একটা SMS |
| Notice | নোটিশ প্রকাশের সময় "Send SMS" চালু থাকলে |
| Exam: Subject Marks | পরীক্ষা থেকে বিষয়ের মার্কস পাঠালে (মাধ্যম হিসেবে SMS বাছাই থাকলে) — কয়েকটা বিষয় একসাথে পাঠালে এক SMS-এ |
| Exam: Result | পরীক্ষার সম্পূর্ণ রেজাল্ট পাঠালে — GPA, গ্রেড, মোট নম্বর ও মেধাক্রম |

**সতর্কতা:** Attendance: Present চালু করলে প্রতিদিন প্রায় প্রতিটা শিক্ষার্থীর জন্য SMS যাবে — খরচ অনেক বেশি হবে। সাধারণত শুধু **Attendance: Absent** চালু রাখা হয়।

## ৬.৭ টেমপ্লেট লেখা ও Placeholder

টেমপ্লেটে `{name}`-এর মতো **placeholder** লিখলে পাঠানোর সময় আসল তথ্য দিয়ে বদলে যায়। টেমপ্লেট ফাঁকা রাখলে ডিফল্ট লেখা ব্যবহার হয়। প্রতিটা টেমপ্লেটের নিচে কয় অক্ষর ও কয় পার্ট হচ্ছে দেখায়।

### Placeholder তালিকা

| Placeholder | অর্থ | কোন Event-এ |
|---|---|---|
| `{name}` | শিক্ষার্থীর নাম | শিক্ষার্থী সংক্রান্ত সব |
| `{name_bn}` | শিক্ষার্থীর বাংলা নাম | শিক্ষার্থী সংক্রান্ত সব |
| `{student_id}` | Student ID | শিক্ষার্থী সংক্রান্ত সব |
| `{school}` | স্কুলের নাম | সব |
| `{class}` | ক্লাস | উপস্থিতি, মেশিন, পরীক্ষা |
| `{date}` | তারিখ | উপস্থিতি, মেশিন, ফি পরিশোধ |
| `{time}` | সময় | মেশিন |
| `{amount}` | টাকা | ফি |
| `{fee_types}` | ফি-এর ধরন | Fee Generated |
| `{receipt_no}` | রসিদ নম্বর | Fee Payment Received |
| `{receipt_link}` | রসিদ যাচাইয়ের লিংক | Fee Payment Received |
| `{title}`, `{body}` | নোটিশের শিরোনাম ও লেখা | Notice |
| `{roll}`, `{exam}` | রোল, পরীক্ষার নাম | পরীক্ষা |
| `{marks}` | বিষয়ের নম্বর (যেমন: গণিত 72/100 (A)) | Exam: Subject Marks |
| `{gpa}`, `{grade}`, `{total_marks}`, `{position}` | GPA, গ্রেড, মোট নম্বর, মেধাক্রম | Exam: Result |

### ডিফল্ট টেমপ্লেট (বাংলা)

| Event | ডিফল্ট লেখা |
|---|---|
| Attendance: Present | প্রিয় অভিভাবক, {name} {date} তারিখে স্কুলে উপস্থিত। - {school} |
| Attendance: Absent | প্রিয় অভিভাবক, {name} {date} তারিখে স্কুলে অনুপস্থিত। - {school} |
| Device: School Entry | প্রিয় অভিভাবক, {name} {time} সময়ে স্কুলে প্রবেশ করেছে। - {school} |
| Device: School Exit | প্রিয় অভিভাবক, {name} {time} সময়ে স্কুল থেকে বের হয়েছে। - {school} |
| Fee Generated | প্রিয় অভিভাবক, {name} (ID: {student_id})-এর {fee_types} বাবদ {amount} টাকা ফি ধার্য হয়েছে। - {school} |
| Fee Payment Received | {name} (ID: {student_id})-এর {amount} টাকা ফি গ্রহণ করা হয়েছে। রসিদ: {receipt_link} - {school} |
| Notice | {school}: নতুন নোটিশ - {title} |
| Exam: Subject Marks | প্রিয় অভিভাবক, {name}-এর {exam} পরীক্ষার নম্বর: {marks} - {school} |
| Exam: Result | প্রিয় অভিভাবক, {name}-এর {exam} পরীক্ষার ফলাফল: GPA {gpa} ({grade}), মোট নম্বর {total_marks}, মেধাক্রম {position}। - {school} |

**টিপস:** টেমপ্লেট ছোট রাখুন। প্রতিটা অতিরিক্ত পার্টে আলাদা খরচ।

## ৬.৮ রিচার্জ (Recharge Request)

**মেনু:** SMS → Recharge Requests (অথবা SMS Settings-এর **Recharge Request** বাটন)

**ধাপ ১:** **New Recharge Request** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বিবরণ |
|---|---|
| Amount (৳) | কত টাকার রিচার্জ চান। নিচে আনুমানিক কতটি SMS হবে দেখায়। |
| Note | মন্তব্য (যেমন কোন নম্বর থেকে টাকা পাঠিয়েছেন) |

**ধাপ ৩:** পাঠান।

**ধাপ ৪:** সফটওয়্যার প্রদানকারী টাকা পরিশোধ নিশ্চিত করলে ব্যালেন্স যোগ করে দেবেন। তখন অনুরোধের Status **Completed** হবে।

### অনুরোধের তালিকা

| কলাম | অর্থ |
|---|---|
| Requested | কখন অনুরোধ |
| Amount | পরিমাণ |
| SMS (approx.) | আনুমানিক SMS |
| Status | **Pending** (অপেক্ষমাণ) / **Completed** (সম্পন্ন) |
| Sent | অনুরোধটি প্রদানকারীর কাছে পৌঁছেছে কিনা |
| Credited | কত টাকা যোগ হয়েছে |
| Requested By | কে অনুরোধ করেছেন |

অনুরোধ পৌঁছায়নি (Sent চিহ্ন নেই) এমন হলে **Resend** চাপুন।

## ৬.৯ Balance History — ব্যালেন্সের হিসাব

**মেনু:** SMS → Balance History

| কলাম | অর্থ |
|---|---|
| Date | তারিখ |
| Type | **Recharge** (যোগ), **SMS Cost** (খরচ), **Refund** (ব্যর্থ SMS-এর টাকা ফেরত) |
| Amount | পরিমাণ |
| SMS | কয় পার্ট |
| Balance | লেনদেনের পরের ব্যালেন্স |
| Description | বিবরণ |

Type দিয়ে ফিল্টার করা যায়।

## ৬.১০ SMS Logs — কোন SMS কখন গেছে

**মেনু:** SMS → SMS Logs

| কলাম | অর্থ |
|---|---|
| Date | কখন তৈরি |
| Recipient | প্রাপকের নাম ও নম্বর |
| Event | কোন ঘটনার SMS |
| Message | লেখা |
| SMS | কয় পার্ট |
| Cost | খরচ |
| Status | **Pending** (পাঠানো হচ্ছে), **Sent** (পাঠানো হয়েছে), **Failed** (ব্যর্থ) |
| Vendor | কোন প্রতিষ্ঠানের মাধ্যমে |
| Code / Error | ব্যর্থ হলে কারণ |
| Sent At | কখন পাঠানো হয়েছে |

**ফিল্টার:** Status, Event, তারিখ (From – Until)।

## ৬.১১ SMS Vendors

**মেনু:** SMS → SMS Vendors

যে প্রতিষ্ঠানের মাধ্যমে SMS পাঠানো হয় তার তালিকা — নাম, Provider, Sender ID, সক্রিয় কিনা, শেষ কখন হালনাগাদ হয়েছে। একাধিক থাকলে ক্রম অনুযায়ী চেষ্টা হয় — প্রথমটা কাজ না করলে পরেরটা দিয়ে।

**মনে রাখুন:** এই তালিকা সফটওয়্যার প্রদানকারী ঠিক করেন। স্কুল থেকে যোগ, সম্পাদনা বা মুছে ফেলা যায় না।

## ৬.১২ সাধারণ প্রশ্ন ও সমাধান

**প্রশ্ন: কোনো SMS যাচ্ছে না।**
উত্তর: (১) **Enable SMS** চালু আছে কিনা; (২) সংশ্লিষ্ট event চালু আছে কিনা; (৩) ব্যালেন্স যথেষ্ট কিনা; (৪) অভিভাবকের সঠিক মোবাইল নম্বর আছে কিনা দেখুন। SMS Logs-এ Failed থাকলে Error কলাম দেখুন।

**প্রশ্ন: পুরো ক্লাসের রেজাল্ট SMS গেল না, কিন্তু ব্যালেন্স আছে।**
উত্তর: ব্যালেন্স সবার খরচের জন্য যথেষ্ট ছিল না, তাই কারও কাছেই যায়নি। রিচার্জ করে আবার পাঠান।

**প্রশ্ন: অনেক বেশি টাকা খরচ হচ্ছে।**
উত্তর: (১) Attendance: Present বন্ধ রাখুন; (২) টেমপ্লেট ছোট করুন; (৩) SMS Language English করুন।

**প্রশ্ন: রিচার্জ করেছি কিন্তু ব্যালেন্স বাড়েনি।**
উত্তর: Recharge Requests-এ Status দেখুন। Pending থাকলে প্রদানকারী এখনো নিশ্চিত করেননি। Sent চিহ্ন না থাকলে **Resend** চাপুন।

**প্রশ্ন: ফোন নম্বর সঠিক কিন্তু SMS যায়নি।**
উত্তর: নম্বরটি বাংলাদেশের সঠিক মোবাইল নম্বর (০১ দিয়ে শুরু, ১১ সংখ্যা) কিনা দেখুন।
