## ৫.১ পরিচিতি

স্কুল থেকে শিক্ষক ও শিক্ষার্থীদের কাছে নোটিশ পাঠানো হয় এখান থেকে। নোটিশ তিনভাবে পৌঁছায়:

1. **প্যানেলে** — শিক্ষক ও শিক্ষার্থী নিজের প্যানেলের **Notices** পেজে দেখতে পান।
2. **Push নোটিফিকেশন** — মোবাইল বা কম্পিউটারে সাথে সাথে বার্তা আসে (অ্যাপ ইনস্টল করা থাকলে সবচেয়ে ভালো কাজ করে)।
3. **SMS** (ঐচ্ছিক) — অভিভাবক বা শিক্ষকের মোবাইলে।

**মেনু:** Communication → Notices

## ৫.২ কে ব্যবহার করতে পারেন

| অনুমতি | কাজ |
|---|---|
| View notices | নোটিশের তালিকা দেখা |
| Create notices | নতুন নোটিশ তৈরি |
| Edit notices | নোটিশ সম্পাদনা |
| Delete notices | নোটিশ মুছে ফেলা |

## ৫.৩ নতুন নোটিশ তৈরি

**ধাপ ১:** **Communication → Notices → New notice** চাপুন।

**ধাপ ২:** **Notice Content** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Title | হ্যাঁ | নোটিশের শিরোনাম, যেমন "শীতকালীন ছুটির নোটিশ" |
| Body | হ্যাঁ | বিস্তারিত লেখা। মোটা, তির্যক, তালিকা, লিংক ইত্যাদি ফরম্যাট করা যায়। |

**ধাপ ৩:** **Target Audience** বেছে নিন ([৫.৪](#৫৪-কাকে-পাঠাবেন-target-audience))।

**ধাপ ৪:** **Publishing** অংশ ঠিক করুন ([৫.৫](#৫৫-এখনই-প্রকাশ-নাকি-নির্দিষ্ট-সময়ে), [৫.৬](#৫৬-নোটিশের-সাথে-sms))।

**ধাপ ৫:** **Create** চাপুন।

`[স্ক্রিনশট: নতুন নোটিশ ফর্ম]`

## ৫.৪ কাকে পাঠাবেন (Target Audience)

**Send To** ঘর থেকে বেছে নিন:

| অপশন | কে পাবে | অতিরিক্ত ঘর |
|---|---|---|
| Everyone | সব শিক্ষক ও সব শিক্ষার্থী। SMS চালু থাকলে সক্রিয় স্টাফরাও SMS পান। | — |
| All Students | সব শিক্ষার্থী | — |
| All Teachers | সব শিক্ষক | — |
| Specific Class(es) | নির্দিষ্ট এক বা একাধিক ক্লাসের শিক্ষার্থী | ক্লাস বেছে নিন |
| Individual Student(s) | নির্দিষ্ট শিক্ষার্থী | **Filter by Class** দিয়ে ক্লাস বেছে, তারপর শিক্ষার্থী |
| Individual Teacher(s) | নির্দিষ্ট শিক্ষক | শিক্ষক বেছে নিন |

**উদাহরণ:**

- পরীক্ষার রুটিন শুধু দশম শ্রেণির জন্য → **Specific Class(es)** → Class 10
- শিক্ষকদের মিটিং → **All Teachers**
- একজন শিক্ষার্থীর অভিভাবককে ডাকা → **Individual Student(s)**

## ৫.৫ এখনই প্রকাশ নাকি নির্দিষ্ট সময়ে

**Schedule At** ঘর:

- **খালি রাখলে** — সাথে সাথে প্রকাশ হবে।
- **ভবিষ্যতের তারিখ ও সময় দিলে** — ঠিক সেই সময়ে নিজে থেকে প্রকাশ হবে। আগের সময় দেওয়া যায় না।

নির্ধারিত সময়ের আগে নোটিশ সম্পাদনা করে সময় বদলালে নতুন সময়েই প্রকাশ হবে।

**মনে রাখুন:** প্রকাশের মুহূর্তেই Push ও SMS পাঠানো হয়।

## ৫.৬ নোটিশের সাথে SMS

**Send SMS** অপশন শুধু তখনই দেখা যায় যখন **SMS → SMS Settings**-এ "Notice" event চালু আছে।

**ধাপ ১:** **Send SMS** চালু করুন।

**ধাপ ২:** নিচে খরচের হিসাব দেখুন: *"প্রাপক ... জন · ... SMS পার্ট · খরচ ৳... · ব্যালেন্স ৳..."*

**ধাপ ৩:** ব্যালেন্স যথেষ্ট হলে নোটিশ সেভ করুন।

**মনে রাখুন:**

- শিক্ষার্থীর জন্য SMS যায় **অভিভাবকের নম্বরে**।
- একই অভিভাবকের দুই সন্তান থাকলে একই মেসেজ একবারই যায়।
- ব্যালেন্স কম থাকলে একটাও SMS যাবে না — সব অথবা কিছুই না।
- SMS-এর লেখা SMS Settings-এর "Notice" টেমপ্লেট অনুযায়ী (ডিফল্ট: *"{স্কুলের নাম}: নতুন নোটিশ - {শিরোনাম}"*)।

## ৫.৭ নোটিশের তালিকা ও কে পড়েছে

**মেনু:** Communication → Notices

| কলাম | অর্থ |
|---|---|
| Title | শিরোনাম |
| Audience | কাকে পাঠানো হয়েছে |
| Status | প্রকাশিত, নির্ধারিত (Scheduled) ইত্যাদি |
| Publish Date | প্রকাশের তারিখ |
| Read | কতজন পড়েছেন |
| SMS | SMS পাঠানো হয়েছে কিনা |
| Created By | কে তৈরি করেছেন |

**ফিল্টার:** Audience।

**View** চাপলে নোটিশের পুরো লেখা, কাকে পাঠানো হয়েছে (Targets), SMS চালু ছিল কিনা, কতজন পড়েছেন, কে কখন তৈরি করেছেন — সব দেখা যায়।

## ৫.৮ শিক্ষক ও শিক্ষার্থী কীভাবে নোটিশ দেখে

- শিক্ষক প্যানেল ও শিক্ষার্থী প্যানেলে **Notices** মেনু আছে। সেখানে তাদের জন্য পাঠানো সব নোটিশ থাকে।
- ড্যাশবোর্ডে সাম্প্রতিক নোটিশ ও না-পড়া নোটিশের সংখ্যা দেখায়।
- নোটিশ খুললে সেটা "পড়া হয়েছে" হিসেবে গোনা হয়।

বিস্তারিত: [শিক্ষক প্যানেল](../panels/teacher-panel.md), [শিক্ষার্থী প্যানেল](../panels/student-panel.md)।

## ৫.৯ Push নোটিফিকেশন — কোন কোন ঘটনায় যায়

Push নোটিফিকেশনের জন্য ব্যবহারকারীকে ব্রাউজারে বা অ্যাপে নোটিফিকেশন **Allow** করতে হয় ([শুরু করা](../00-getting-started.md))।

| ঘটনা | কে পায় |
|---|---|
| নতুন নোটিশ প্রকাশ | নোটিশের প্রাপকরা |
| উপস্থিতি নেওয়া বা বদলানো | শিক্ষার্থী |
| মেশিনে প্রবেশ / বের হওয়া | শিক্ষার্থী |
| নতুন ফি ইনভয়েস, ইনভয়েস সংশোধন | শিক্ষার্থী |
| ফি পরিশোধ | শিক্ষার্থী |
| বিষয়ের মার্কস পাঠানো, রেজাল্ট প্রকাশ | শিক্ষার্থী |
| বেতনের ইনভয়েস তৈরি, বেতন পরিশোধ | শিক্ষক / স্টাফ |

**মনে রাখুন:** কোনো ডিভাইস নোটিফিকেশন পেয়েছে কিনা সিস্টেম খেয়াল রাখে। না পেলে কিছুক্ষণ পর পর কয়েকবার আবার পাঠানো হয়। প্যানেলের উপরের ঘণ্টা আইকনেও সব নোটিফিকেশন জমা থাকে।

## ৫.১০ সাধারণ প্রশ্ন ও সমাধান

**প্রশ্ন: Send SMS অপশন দেখা যাচ্ছে না।**
উত্তর: SMS → SMS Settings-এ **Enable SMS** এবং **Notice** event চালু করুন।

**প্রশ্ন: শিক্ষার্থী নোটিশ পায়নি।**
উত্তর: (১) Target Audience-এ সে আছে কিনা; (২) Schedule At-এর সময় পার হয়েছে কিনা; (৩) শিক্ষার্থী Active কিনা দেখুন।

**প্রশ্ন: Push নোটিফিকেশন আসছে না।**
উত্তর: ব্যবহারকারীর ব্রাউজারে নোটিফিকেশন Allow করা আছে কিনা দেখুন। অ্যাপ হিসেবে ইনস্টল করে নিলে ভালো হয়।

**প্রশ্ন: ভুল নোটিশ পাঠিয়ে ফেলেছি।**
উত্তর: নোটিশ Edit করে সংশোধন করুন অথবা Delete করুন। তবে যে Push বা SMS আগেই চলে গেছে তা ফেরানো যায় না।
