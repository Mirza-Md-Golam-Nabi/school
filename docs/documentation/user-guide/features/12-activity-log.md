## ১২.১ পরিচিতি

সিস্টেমে কে, কখন, কী তৈরি, পরিবর্তন বা মুছে ফেলেছেন — সব কিছুর রেকর্ড এখানে থাকে। ভুল খুঁজে বের করা, হিসাব মেলানো বা কোনো পরিবর্তনের দায়িত্ব নির্ধারণে এটা কাজে লাগে।

**মেনু:** Activity Log → Activity Log

## ১২.২ কে ব্যবহার করতে পারেন

যাদের **View activity log** অনুমতি আছে। এখানে শুধু দেখা যায়, কিছু বদলানো বা মুছে ফেলা যায় না।

## ১২.৩ কী কী রেকর্ড হয়

| ঘটনা (Event) | উদাহরণ |
|---|---|
| Created | নতুন শিক্ষার্থী, ইনভয়েস, পরীক্ষা, নোটিশ তৈরি |
| Updated | মার্কস বদলানো, ফি সংশোধন, উপস্থিতি বদলানো |
| Deleted | কোনো রেকর্ড মুছে ফেলা |
| Restored | মুছে ফেলা রেকর্ড ফেরত আনা |
| Login | কেউ লগইন করেছেন |
| Logout | কেউ লগআউট করেছেন |
| Failed Login | ভুল পাসওয়ার্ড দিয়ে লগইনের চেষ্টা |
| Calculated | মেধাক্রম হিসাব |
| Generated | ইনভয়েস, অ্যাডমিট কার্ড, মার্কশিট তৈরি |

প্রায় সব মডিউলের পরিবর্তন রেকর্ড হয় — প্রোফাইল, ক্লাস, পরীক্ষা, মার্কস, উপস্থিতি, ফি, বেতন, ফান্ড, ছুটি, নোটিশ, রোল ও অনুমতি, সেটিংস।

## ১২.৪ লগের তালিকা

| কলাম | অর্থ |
|---|---|
| Time | কখন |
| User | কে করেছেন |
| Module | কোন অংশে (যেমন exam_type, merit_ranking) |
| Event | কী ঘটনা |
| Subject | কোন ধরনের রেকর্ডে |
| Description | সংক্ষিপ্ত বিবরণ, যেমন *"Created exam type "Yearly"."* |

**ফিল্টার:** Module, Event।

## ১২.৫ একটা লগের বিস্তারিত

তালিকায় কোনো লগে ক্লিক করলে বিস্তারিত পেজ খোলে:

| অংশ | কী থাকে |
|---|---|
| সাধারণ তথ্য | User, Event, Module, Subject Type, Subject ID, Time, Description |
| Old Value | পরিবর্তনের আগের মান |
| New Value | পরিবর্তনের পরের মান |
| অতিরিক্ত তথ্য | অন্যান্য তথ্য |

**উদাহরণ:** কোনো শিক্ষার্থীর গণিতের মার্কস ৪৫ থেকে ৬৫ করা হলে Old Value-তে ৪৫ আর New Value-তে ৬৫ দেখাবে, সাথে কে ও কখন বদলেছেন।

## ১২.৬ লগ কতদিন থাকে

**৭৩০ দিনের (প্রায় ২ বছর) পুরনো লগ** প্রতি রবিবার রাতে নিজে থেকে মুছে যায়।

## ১২.৭ ব্যবহারের উদাহরণ

| প্রশ্ন | কীভাবে খুঁজবেন |
|---|---|
| একজন শিক্ষার্থীর মার্কস কে বদলেছে? | Event = Updated, Description-এ শিক্ষার্থীর নাম খুঁজুন |
| কোনো পেমেন্ট কে মুছেছে? | Event = Deleted |
| কেউ কি অন্যের অ্যাকাউন্টে ঢোকার চেষ্টা করেছে? | Event = Failed Login |
| রোলের অনুমতি কে বদলেছে? | Module-এ role সংক্রান্ত, Event = Updated |
