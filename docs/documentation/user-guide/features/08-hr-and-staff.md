## ৮.১ পরিচিতি

শিক্ষক ও স্টাফের ছুটি, ভারপ্রাপ্ত দায়িত্ব এবং স্কুলের ছুটির দিন এখান থেকে পরিচালিত হয়।

**মেনু:** বাম পাশের **HR & Staff Management** গ্রুপ:

| মেনু | কাজ |
|---|---|
| Leave Types | ছুটির ধরন (নৈমিত্তিক, অসুস্থতা, মাতৃত্বকালীন ...) |
| Leave Applications | ছুটির আবেদন, অনুমোদন ও বাতিল |
| Acting Admins | নির্দিষ্ট সময়ের জন্য ভারপ্রাপ্ত অ্যাডমিন |
| Public Holidays | সরকারি ও স্কুলের ছুটির দিন |

## ৮.২ কে ব্যবহার করতে পারেন

| অনুমতি | কাজ |
|---|---|
| View / Create / Edit / Delete leave types | ছুটির ধরন |
| View / Create leave applications | আবেদন দেখা ও করা |
| Approve leave applications | অনুমোদন |
| Reject leave applications | বাতিল |
| View / Create / Edit / Delete public holidays | ছুটির দিন |
| View / Create / Edit / Delete acting admins | ভারপ্রাপ্ত অ্যাডমিন |

শিক্ষকরা নিজের প্যানেল থেকে ছুটির আবেদন করেন এবং বাকি ছুটি দেখেন ([শিক্ষক প্যানেল](../panels/teacher-panel.md))।

## ৮.৩ Leave Types — ছুটির ধরন

**মেনু:** HR & Staff Management → Leave Types

**ধাপ ১:** **New leave type** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Name | হ্যাঁ | যেমন Casual Leave, Sick Leave, Maternity Leave |
| Allowed Days Per Year | হ্যাঁ | বছরে কত দিন |
| Applicable To | হ্যাঁ | **Male**, **Female** অথবা **For All** |
| Is Active | — | নিষ্ক্রিয় ছুটিতে নতুন আবেদন করা যায় না |

**ধাপ ৩:** **Create** চাপুন।

**উদাহরণ:**

| ছুটি | দিন / বছর | কার জন্য |
|---|---|---|
| Casual Leave | ১০ | For All |
| Sick Leave | ১৪ | For All |
| Maternity Leave | ১২০ | Female |

## ৮.৪ কাকে কোন ছুটি দেওয়া যাবে (Assign)

ছুটির ধরন তৈরির পর কোন শিক্ষক বা স্টাফ সেটা নিতে পারবেন তা ঠিক করতে হয়।

**ধাপ ১:** Leave Types-এ ছুটির ধরনের **Edit** খুলুন।

**ধাপ ২:** নিচের তালিকায় **Assign** চাপুন।

**ধাপ ৩:** **Type** (Teacher / Staff) ও **Person** বেছে নিন।

**ধাপ ৪:** সেভ করুন।

তালিকায় দেখা যায় কাকে, কে, কখন বরাদ্দ দিয়েছেন। সরাতে **Unassign** চাপুন।

**মনে রাখুন:** আবেদনের সময় শুধু সেই ছুটির ধরনগুলোই দেখায় যেগুলো আবেদনকারীকে বরাদ্দ দেওয়া আছে। ছুটির "Applicable To" অনুযায়ী (যেমন শুধু Female) সঠিক ব্যক্তিদেরই বরাদ্দ দিন।

## ৮.৫ Leave Applications — ছুটির আবেদন

**মেনু:** HR & Staff Management → Leave Applications

অ্যাডমিন কোনো শিক্ষক বা স্টাফের পক্ষে আবেদন করতে পারেন (যেমন কাগজে আবেদন এলে)।

**ধাপ ১:** **New leave application** চাপুন।

**ধাপ ২:** **Applicant** অংশ — **Applicant Type** (Teacher / Staff) ও **Applicant** বেছে নিন।

**ধাপ ৩:** **Leave Details** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Leave Type | হ্যাঁ | শুধু আবেদনকারীকে বরাদ্দ দেওয়া ছুটি দেখায় |
| From Date | হ্যাঁ | শুরুর তারিখ |
| To Date | হ্যাঁ | শেষের তারিখ |
| Total Working Days | হ্যাঁ | নিজে থেকে হিসাব হয় — সাপ্তাহিক ও সরকারি ছুটি বাদ দিয়ে |
| Reason | হ্যাঁ | কারণ |

**ধাপ ৪:** **Create** চাপুন। আবেদনটি **Pending** অবস্থায় থাকবে।

**উদাহরণ:** বৃহস্পতিবার থেকে রবিবার ছুটি চাইলে, শুক্র-শনি সাপ্তাহিক ছুটি হলে Total Working Days = ২ (বৃহস্পতি ও রবি)।

### আবেদনের তালিকা

| কলাম | অর্থ |
|---|---|
| Applicant, Type | আবেদনকারী ও ধরন (শিক্ষক/স্টাফ) |
| Leave Type | ছুটির ধরন |
| From / To / Days | সময় ও কার্যদিবস |
| Status | **Pending**, **Approved**, **Rejected**, **Cancelled** |
| Applied By | কে আবেদন জমা দিয়েছেন |
| Actioned By | কে সিদ্ধান্ত দিয়েছেন |

## ৮.৬ আবেদন অনুমোদন ও বাতিল

শুধু **Pending** আবেদনে এই বাটনগুলো দেখায়।

### অনুমোদন

**ধাপ ১:** আবেদনের সারিতে **Approve** চাপুন।

**ধাপ ২:** চাইলে **Remarks (optional)** লিখুন।

**ধাপ ৩:** নিশ্চিত করুন।

অনুমোদনের পর ছুটির প্রতিটা কার্যদিবসের জন্য "ছুটিতে আছেন" রেকর্ড তৈরি হয়। এই দিনগুলোতে ফিঙ্গারপ্রিন্ট মেশিনের স্বয়ংক্রিয় Absent এই ব্যক্তিকে Absent করে না।

### বাতিল

**ধাপ ১:** **Reject** চাপুন।

**ধাপ ২:** **Reason for rejection** লিখুন।

**ধাপ ৩:** নিশ্চিত করুন।

**মনে রাখুন:**

- অনুমোদিত আবেদন আর সম্পাদনা করা যায় না।
- **View** চাপলে আবেদনের বিস্তারিত — আবেদনকারী, ভূমিকা, সময়, কার্যদিবস, ছুটির ধরন, এবং সিদ্ধান্ত হয়ে থাকলে কে ও কখন সিদ্ধান্ত দিয়েছেন।
- ছুটির সময়ের মধ্যে কেউ উপস্থিত হলে (যেমন আগে কাজে ফিরলে) সেই দিন "Joined Early" হিসেবে চিহ্নিত হয়।

## ৮.৭ ছুটি শেষে কাজে না ফিরলে

প্রতিদিন সকাল ৮টায় সিস্টেম দেখে, যাদের অনুমোদিত ছুটি শেষ হয়ে গেছে কিন্তু এরপরেও টানা অনুপস্থিত, তাদের জন্য **অতিরিক্ত অনুপস্থিতি (Absent Excess)** রেকর্ড তৈরি হয়। পরের প্রথম উপস্থিত বা দেরিতে উপস্থিত দিন পর্যন্ত গোনা হয়।

## ৮.৮ Acting Admins — ভারপ্রাপ্ত অ্যাডমিন

**মেনু:** HR & Staff Management → Acting Admins

প্রধান শিক্ষক বা অ্যাডমিন ছুটিতে বা বাইরে থাকলে অন্য একজন শিক্ষক বা স্টাফকে নির্দিষ্ট সময়ের জন্য অ্যাডমিনের দায়িত্ব দেওয়া যায়। তিনি সেই সময় অ্যাডমিন প্যানেলে ঢুকতে পারবেন।

**ধাপ ১:** **New acting admin** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Acting User | হ্যাঁ | কাকে দায়িত্ব দেবেন |
| Acting As | হ্যাঁ | **Acting Super Admin** অথবা **Acting Admin** |
| From Date | হ্যাঁ | কবে থেকে |
| To Date | না | কবে পর্যন্ত। খালি রাখলে হাতে সরানো বা বন্ধ না করা পর্যন্ত চলবে। |
| Is Active | হ্যাঁ | চালু / বন্ধ |
| Remarks | না | মন্তব্য |

**ধাপ ৩:** **Create** চাপুন।

### দুই ধরনের দায়িত্ব

| ধরন | কী করতে পারেন |
|---|---|
| Acting Super Admin | প্রায় সব কাজ — **শুধু School Settings সম্পাদনা ছাড়া** |
| Acting Admin | ঠিক যতটুকু অনুমতি "admin" রোলের আছে, ততটুকু। admin রোলের অনুমতি বদলালে এটাও বদলে যায়। |

**মনে রাখুন:**

- **To Date পার হলে পরের দিন রাত ১২:১০-এ দায়িত্ব নিজে থেকে বন্ধ হয়ে যায়।**
- **সতর্কতা:** From Date ভবিষ্যতের কোনো তারিখ দিলে সেই দিন এলে দায়িত্ব নিজে থেকে চালু হয় **না**। তাই দায়িত্ব যেদিন শুরু হবে সেদিনই রেকর্ডটি তৈরি করুন, অথবা সেদিন রেকর্ডটি খুলে একবার **Save** করুন।
- আগে বন্ধ করতে **Is Active** বন্ধ করুন অথবা রেকর্ডটি মুছে দিন।
- তালিকায় দেখা যায় কে দায়িত্ব দিয়েছেন, ধরন, সময় ও সক্রিয় কিনা।

## ৮.৯ Public Holidays — সরকারি ও স্কুলের ছুটি

**মেনু:** HR & Staff Management → Public Holidays

এখানে দেওয়া দিনগুলো কার্যদিবস হিসেবে গোনা হয় না — উপস্থিতি, ছুটির হিসাব, স্বয়ংক্রিয় Absent ও রিপোর্ট সব জায়গায়।

**ধাপ ১:** **New public holiday** চাপুন।

**ধাপ ২:** পূরণ করুন:

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Name | হ্যাঁ | যেমন বিজয় দিবস, ঈদুল ফিতর, শীতকালীন ছুটি |
| Holiday Type | — | **Single Day** (এক দিন) অথবা **Date Range** (কয়েক দিন) |
| Date / Start Date | হ্যাঁ | তারিখ বা শুরুর তারিখ |
| End Date | Date Range হলে | শেষের তারিখ |
| Repeats Every Year | — | প্রতি বছর একই তারিখে (যেমন ২১ ফেব্রুয়ারি, ১৬ ডিসেম্বর) |
| Description | না | বিবরণ |

**ধাপ ৩:** **Create** চাপুন।

**টিপস:** ঈদের মতো যে ছুটির তারিখ প্রতি বছর বদলায়, সেগুলোতে "Repeats Every Year" বন্ধ রাখুন এবং প্রতি বছর আলাদা করে দিন।

**মনে রাখুন:** সাপ্তাহিক ছুটি (যেমন শুক্র-শনি) এখানে নয় — **School Settings** থেকে ঠিক করুন ([School Settings](13-school-settings.md))।

## ৮.১০ সাধারণ প্রশ্ন ও সমাধান

**প্রশ্ন: আবেদনের সময় Leave Type তালিকা খালি।**
উত্তর: আবেদনকারীকে কোনো ছুটির ধরন বরাদ্দ (Assign) দেওয়া নেই। Leave Types → Edit → Assign করুন।

**প্রশ্ন: Total Working Days ভুল দেখাচ্ছে।**
উত্তর: School Settings-এ সাপ্তাহিক ছুটির দিন ও Public Holidays ঠিক আছে কিনা দেখুন।

**প্রশ্ন: অনুমোদিত আবেদন সম্পাদনা করতে পারছি না।**
উত্তর: অনুমোদনের পর সম্পাদনা বন্ধ থাকে।

**প্রশ্ন: ভারপ্রাপ্ত অ্যাডমিন লগইন করতে পারছেন না।**
উত্তর: From Date শুরু হয়েছে কিনা, To Date পার হয়নি কিনা, এবং Is Active চালু আছে কিনা দেখুন। Acting Admin হলে admin রোলে প্রয়োজনীয় অনুমতি আছে কিনা দেখুন।

**প্রশ্ন: বছরে নির্ধারিত দিনের বেশি ছুটি দেওয়া যায় কি?**
উত্তর: সিস্টেম আবেদন আটকায় না। শিক্ষক নিজের প্যানেলে বাকি ছুটি দেখতে পান। অনুমোদনের আগে অ্যাডমিন নিজে মিলিয়ে নিন।
