## ৩.১ পরিচিতি

এখানে স্কুলের সবার তথ্য রাখা হয় — শিক্ষার্থী, শিক্ষক ও স্টাফ। প্রোফাইল তৈরি করলেই তার একটা লগইন অ্যাকাউন্ট তৈরি হয়ে যায়।

**মেনু:** বাম পাশের **User Profile** গ্রুপ:

| মেনু | কাজ |
|---|---|
| Students | শিক্ষার্থী ভর্তি, তথ্য, ঐচ্ছিক বিষয়, পাসওয়ার্ড রিসেট |
| Teachers | শিক্ষক |
| Staff | স্টাফ (অফিস সহকারী, হিসাবরক্ষক ইত্যাদি) |
| Promote | বছর শেষে শিক্ষার্থীদের পরের ক্লাসে উত্তীর্ণ করা |

## ৩.২ কে ব্যবহার করতে পারেন

প্রতিটা প্রোফাইলের ধরনের জন্য আলাদা অনুমতি: দেখা (View), তৈরি (Create), সম্পাদনা (Edit), মুছে ফেলা (Delete), ফেরত আনা (Restore), চিরতরে মুছে ফেলা (Force delete)। Super Admin "Roles & Permissions" থেকে এগুলো দেন।

## ৩.৩ শিক্ষার্থীর তালিকা

**মেনু:** User Profile → Students

প্রথমে প্রতিটা সক্রিয় ক্লাসের একটা কার্ড দেখা যায়, প্রতিটায় চলতি শিক্ষাবর্ষের সক্রিয় শিক্ষার্থীর সংখ্যা। কার্ডে ক্লিক করলে সেই ক্লাসের শিক্ষার্থীর তালিকা খোলে।

`[স্ক্রিনশট: Students — ক্লাস কার্ড]`

ক্লাসের পেজে উপরে গ্রুপ অনুযায়ী শিক্ষার্থীর সংখ্যা দেখায় (গ্রুপওয়ালা ক্লাসে)। তালিকার কলাম:

| কলাম | অর্থ |
|---|---|
| Photo | অফিসিয়াল ছবি |
| Name | নাম |
| Roll No | রোল |
| Student ID | ৮ সংখ্যার লগইন আইডি |
| Section / Group | শুধু সেকশন বা গ্রুপওয়ালা ক্লাসে |
| Session | শিক্ষাবর্ষ |
| Status | Active, Inactive ইত্যাদি |
| Gender, Admission | লিঙ্গ, ভর্তির তারিখ |

**ফিল্টার:** Status, Class (সব ক্লাসের তালিকায়), Group (গ্রুপওয়ালা ক্লাসে), মুছে ফেলা শিক্ষার্থী।

**সারির বাটন:** View (দেখা), Edit (সম্পাদনা), Delete (মুছে ফেলা), Restore (ফেরত আনা)।

## ৩.৪ নতুন শিক্ষার্থী ভর্তি

**ধাপ ১:** ক্লাসের পেজে **New student profile** চাপুন। ক্লাস আগে থেকে বাছাই করা থাকবে।

**ধাপ ২:** ফর্মের অংশগুলো পূরণ করুন।

### Account Information

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Name (Bangla) | হ্যাঁ | বাংলা নাম |
| Name (English) | না | খালি রাখলে বাংলা নামটাই সব জায়গায় দেখাবে |
| Student Photo (Official) | না | আইডি কার্ড, অ্যাডমিট কার্ড ও মার্কশিটে এই ছবিই ছাপা হয়। ছবি কাটার সুবিধা আছে। |

**মনে রাখুন:** ছবি না দিলে ডকুমেন্টে লিঙ্গ অনুযায়ী একটা ডিফল্ট ছবি ছাপা হয়।

### Academic Information

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Roll No | হ্যাঁ | ১ বা তার বেশি সংখ্যা |
| Registration No | না | শুধু সংখ্যা |
| Session Year | হ্যাঁ | শিক্ষাবর্ষ (ডিফল্ট চলতি) |
| Class | হ্যাঁ | ক্লাস |
| Section | ক্লাসে সেকশন থাকলে | |
| Group | ক্লাসে গ্রুপ থাকলে | |
| Main Optional Subject | গ্রুপে ঐচ্ছিক বিষয় থাকলে | প্রধান ঐচ্ছিক বিষয় (GPA-তে পুরো গোনা হয়) |
| Extra Optional Subject | গ্রুপে ঐচ্ছিক বিষয় থাকলে | ৪র্থ বিষয়। Main Optional-এর সাথে একই হতে পারবে না। |
| Admission Date | না | ভর্তির তারিখ |
| Status | হ্যাঁ | ডিফল্ট Active |

### Personal Information

| ঘর | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| Gender | হ্যাঁ | Male / Female / Other |
| Date of Birth | না | জন্ম তারিখ |
| Birth Certificate No | না | জন্ম নিবন্ধন নম্বর (শুধু সংখ্যা) — নিচের গুরুত্বপূর্ণ নিয়ম দেখুন |
| Blood Group | না | A+, A-, B+, B-, AB+, AB-, O+, O- |
| Religion | না | ডিফল্ট Muslim |
| Nationality | হ্যাঁ | ডিফল্ট Bangladeshi |

### Family Information

বাবা, মা ও অভিভাবকের নাম, পেশা ও ছবি। অভিভাবকের ক্ষেত্রে সম্পর্ক ও **Guardian's Phone** (সর্বোচ্চ ১৫ সংখ্যা)।

**সতর্কতা:** **Guardian's Phone** অবশ্যই সঠিকভাবে দিন। উপস্থিতি, ফি ও রেজাল্টের সব SMS এই নম্বরে যায়।

### Address

**Present Address** (বর্তমান ঠিকানা)। স্থায়ী ঠিকানা একই হলে **Permanent address is same as present address** চালু করুন, না হলে **Permanent Address** আলাদা লিখুন।

**ধাপ ৩:** **Create** চাপুন।

### জন্ম নিবন্ধন নম্বর দিয়ে পুরনো শিক্ষার্থী শনাক্ত

নতুন ভর্তির সময় যদি দেওয়া **Birth Certificate No** আগে থেকেই সিস্টেমে থাকে (যেমন কোনো শিক্ষার্থী আগে ছিল, চলে গিয়ে আবার ফিরে এসেছে):

- ফর্মে সাথে সাথে পুরনো **Student ID** দেখাবে, আর সতর্কবার্তা আসবে।
- নতুন অ্যাকাউন্ট তৈরি **হবে না**। পুরনো Student ID-তেই তথ্য আপডেট হবে।
- পাসওয়ার্ড রিসেট হয়ে যাবে।

## ৩.৫ শিক্ষার্থীর লগইন তথ্য

শিক্ষার্থী তৈরি হওয়ার সাথে সাথে একটা বক্স দেখায় — **Student Login তৈরি হয়েছে**:

| তথ্য | মান |
|---|---|
| Student ID | ৮ সংখ্যার আইডি (যেমন ১০১০০০২৫) |
| Password | `password` |

**ধাপ:** এই তথ্য লিখে রাখুন বা কপি করে শিক্ষার্থী/অভিভাবককে দিন।

**মনে রাখুন:**

- Student ID সিস্টেম নিজে তৈরি করে, পরিবর্তন করা যায় না।
- প্রথম লগইনেই শিক্ষার্থীকে নতুন পাসওয়ার্ড ও ৪ সংখ্যার Recovery PIN দিতে হবে ([শুরু করা](../00-getting-started.md))।

### শিক্ষার্থীর পাসওয়ার্ড রিসেট

শিক্ষার্থী পাসওয়ার্ড ও PIN দুটোই ভুলে গেলে:

**ধাপ ১:** শিক্ষার্থীর View বা Edit পেজে **Reset Password** চাপুন।

**ধাপ ২:** নিশ্চিত করুন।

ফলে পাসওয়ার্ড আবার `password` হবে, Recovery PIN মুছে যাবে, আর পরের লগইনে শিক্ষার্থীকে নতুন পাসওয়ার্ড ও PIN দিতে হবে।

## ৩.৬ Excel থেকে একসাথে অনেক শিক্ষার্থী

**ধাপ ১:** Students পেজে (অথবা কোনো ক্লাসের পেজে) **Import (Excel)** → **Download Demo File** চাপুন।

**ধাপ ২:** **Students** শিটে প্রতি সারিতে একজন শিক্ষার্থী লিখুন। **Instructions** শিটে নিয়ম আছে।

| কলাম | বাধ্যতামূলক | নিয়ম |
|---|---|---|
| roll_no | হ্যাঁ | শুধু সংখ্যা |
| name_bn | হ্যাঁ | বাংলা নাম |
| name | না | ইংরেজি নাম |
| class | হ্যাঁ | সিস্টেমের ক্লাসের নাম হুবহু। ক্লাসের পেজ থেকে আপলোড করলে খালি রাখা যায়। |
| section | না | সেই ক্লাসের সেকশনের নাম |
| group | না | সেই ক্লাসের গ্রুপের নাম |
| session_year | না | খালি রাখলে চলতি শিক্ষাবর্ষ। কলেজে শুরুর বছর (২০২৬-২৭ হলে ২০২৬)। |
| gender | হ্যাঁ | male / female / other |
| registration_no | না | শুধু সংখ্যা |
| admission_date, date_of_birth | না | YYYY-MM-DD অথবা DD/MM/YYYY |
| birth_certificate_no | না | কলামটি Text ফরম্যাটে রাখুন। আগে থেকে থাকা নম্বর হলে সেই শিক্ষার্থীর তথ্য আপডেট হবে। |
| blood_group | না | A+ / A- / B+ / B- / AB+ / AB- / O+ / O- |
| religion | না | muslim / hindu / christian / buddhist / other |
| nationality | না | খালি রাখলে Bangladeshi |
| father_name, father_occupation, mother_name, mother_occupation | না | |
| guardian_name, guardian_relation, guardian_occupation | না | |
| guardian_phone | না | সর্বোচ্চ ১৫ সংখ্যা। Text ফরম্যাটে রাখুন, নইলে শুরুর ০ হারিয়ে যায়। |
| present_address, permanent_address | না | স্থায়ী ঠিকানা খালি রাখলে শুধু বর্তমান ঠিকানা সেভ হবে |
| main_optional_subject | না | শুধু গ্রুপ থাকলে — সেই গ্রুপের ঐচ্ছিক বিষয়ের নাম |
| extra_optional_subject | না | Main Optional থেকে আলাদা হতে হবে |

**ধাপ ৩:** **Import (Excel)** → **Upload Excel File** → ফাইল বেছে **Import** চাপুন।

**মনে রাখুন:**

- একবারে সর্বোচ্চ ১০০০ জন।
- **কোনো একটা সারিতে ভুল থাকলে কেউই যোগ হবে না।** ভুলগুলো দেখাবে। ঠিক করে আবার আপলোড করুন।
- সফল হলে সবার পাসওয়ার্ড হবে `password`। প্রত্যেকের Student ID তার প্রোফাইলে দেখা যাবে।
- একই ক্লাস, সেকশন ও শিক্ষাবর্ষে একাধিক শিক্ষার্থীর একই রোল থাকলে সতর্কবার্তা আসে, কিন্তু import আটকায় না।

## ৩.৭ শিক্ষার্থীর প্রোফাইল দেখা ও সম্পাদনা

### দেখা (View)

তালিকায় **View** (চোখ আইকন) চাপলে প্রোফাইল খোলে। ট্যাবগুলো:

| ট্যাব | কী থাকে |
|---|---|
| Basic Info | Student ID, রোল, রেজিস্ট্রেশন, শিক্ষাবর্ষ, ক্লাস, সেকশন, গ্রুপ, ভর্তির তারিখ, স্ট্যাটাস, ব্যক্তিগত তথ্য |
| Guardian Info | বাবা, মা ও অভিভাবকের তথ্য ও ছবি |
| Address | বর্তমান ও স্থায়ী ঠিকানা |
| Fee Summary | ফি-এর সারসংক্ষেপ — মোট, পরিশোধিত, বকেয়া |
| Subjects | শিক্ষার্থী কোন কোন বিষয় পড়ে (বাধ্যতামূলক, ঐচ্ছিক, ৪র্থ) |

Student ID-এর পাশে কপি বাটন আছে।

### সম্পাদনা (Edit)

**Edit** চাপুন, তথ্য বদলান, **Save changes** চাপুন।

Edit পেজের উপরের বাটনগুলো:

| বাটন | কাজ |
|---|---|

## ৩.১২ Promote — পরের ক্লাসে উত্তীর্ণ করা

**মেনু:** User Profile → Promote

বছর শেষে বার্ষিক পরীক্ষার পর শিক্ষার্থীদের পরের ক্লাসে তোলা হয়।

### প্রমোশনের আগে যা করা দরকার

1. বার্ষিক (Main) পরীক্ষার মার্কস এন্ট্রি শেষ করুন।
2. সেই পরীক্ষার **Calculate Rankings** চালান — নতুন রোল মেধাক্রম থেকে আসে।
3. পরের শিক্ষাবর্ষের ফি কাঠামো তৈরি করুন (ফি আদায় করতে চাইলে)।

### ধাপে ধাপে

**ধাপ ১:** **Session Year** বেছে নিন (চলতি বা আগের বছর)। প্রতিটা ক্লাসের কার্ডে সেই বছরের সক্রিয় শিক্ষার্থীর সংখ্যা দেখায়।

**ধাপ ২:** যে ক্লাসের শিক্ষার্থী প্রমোট করবেন তার কার্ডে ক্লিক করুন।

**ধাপ ৩:** দুইভাবে প্রমোট করা যায়:

| পদ্ধতি | কখন |
|---|---|
| **একজন একজন করে** — সারির **Promote** বাটন | কারও জন্য আলাদা সিদ্ধান্ত বা ফি আদায় একসাথে করতে চাইলে |
| **সবাই একসাথে** — উপরের **Bulk Promote** বাটন | পুরো ক্লাস একসাথে |

### একজনকে প্রমোট করা

**Promote** চাপলে একটা ফর্ম খোলে:

| ঘর | বিবরণ |
|---|---|
| Status | **Promoted** (পরের ক্লাসে), **Repeated** (একই ক্লাসে আবার), **Graduated** (পাস করে বের হয়েছে), **Transferred** (বদলি), **Dropped** (ঝরে পড়েছে) |
| Target Class | নতুন ক্লাস। Promoted-এ নিজে থেকে পরের ক্লাস, Repeated-এ একই ক্লাস বসে। |
| Section, Group | নতুন ক্লাসের। আগের গ্রুপ নতুন ক্লাসে থাকলে সেটিই বসে। |
| Main / Extra Optional Subject | সাধারণত আগের বিষয়ই থাকে। গ্রুপ বা বিষয় বদলালে নতুন করে বেছে নিন। |
| New Roll (Merit) | নতুন রোল। ক্লাসের "Roll On Promotion" = Merit হলে মূল পরীক্ষার মেধাক্রম থেকে আসে, "আগের রোল থাকবে" হলে আগের রোল। হাতে বদলানো যায়। |
| Final Merit Rank (Main Exam) | মূল পরীক্ষায় মেধাক্রম (শুধু দেখার জন্য) |
| Remarks | মন্তব্য |

**Fee Collection (ঐচ্ছিক):** প্রমোশনের সাথেই নতুন ক্লাসের ফি আদায় করা যায়।

| ঘর | বিবরণ |
|---|---|
| Fees to Collect | নতুন ক্লাস ও নতুন শিক্ষাবর্ষের কোন কোন ফি (যেমন ভর্তি ফি, সেশন ফি) |
| Months (Monthly Fees) | মাসিক ফি হলে কোন কোন মাস |
| Total Payable | মোট দেয় (ছাড় ও আগে দেওয়া টাকা বাদে) |
| Amount Received | কত টাকা পেলেন। কম দিলে বাকিটা বকেয়া থাকবে। ০ বা খালি রাখলে শুধু ইনভয়েস তৈরি হবে। |
| Payment Method, Receipt No., Payment Date, Transaction / Cheque No. | পেমেন্টের তথ্য |

**সাবমিট** করুন। ফি নেওয়া হলে *"Fee payment recorded"* আসবে, সাথে **Download Payment Slip** বাটন।

### সবাইকে একসাথে (Bulk Promote)

**ধাপ ১:** **Bulk Promote** চাপুন। সব শিক্ষার্থীর একটা তালিকা খোলে, প্রত্যেকের জন্য Status, Target Class, Section, Group, ঐচ্ছিক বিষয় ও New Roll আগে থেকেই পূরণ থাকে।

**ধাপ ২:** কারও জন্য বদলাতে হলে তার সারিতে বদলান (যেমন একজনকে Repeated)।

**ধাপ ৩:** **Promote Students** চাপুন এবং নিশ্চিত করুন।

**ধাপ ৪:** সফল হলে লেখা আসবে *"Students promoted successfully"*।

### প্রমোশনে কী হয়

| Status | শিক্ষার্থীর কী হয় |
|---|---|
| Promoted | নতুন ক্লাস, নতুন রোল, শিক্ষাবর্ষ এক বছর বাড়ে, Active থাকে |
| Repeated | একই (বা বেছে নেওয়া) ক্লাস, নতুন রোল, শিক্ষাবর্ষ এক বছর বাড়ে, Active থাকে |
| Graduated | স্ট্যাটাস Graduated |
| Transferred | স্ট্যাটাস Transferred |
| Dropped | স্ট্যাটাস Dropped |

- আগের ক্লাস, রোল ও শিক্ষাবর্ষ ইতিহাস হিসেবে সংরক্ষিত থাকে। শিক্ষার্থী নিজের প্যানেলের **Academic History**-তে তা দেখতে পায়।
- আগের ক্লাসের ঐচ্ছিক বিষয় বাছাইও ইতিহাসে থেকে যায়।
- শেষ ক্লাসে (যেমন দশম) পরের কোনো ক্লাস না থাকলে সাধারণত Graduated।

**মনে রাখুন:**

- Promoted বা Repeated হলে **Target Class ও New Roll অবশ্যই দিতে হবে**।
- Main Optional ও Extra Optional একই বিষয় হতে পারবে না।
- একই ক্লাস, সেকশন ও শিক্ষাবর্ষে একই রোল একাধিক জনের হলে **সতর্কবার্তা আসে, কিন্তু আটকায় না**। প্রয়োজনে রোল বদলান।
- কোনো শিক্ষার্থীর বকেয়া "ডিফল্ট" হিসেবে চিহ্নিত থাকলে প্রমোশন আটকায় না, শুধু নিশ্চিতকরণে জানানো হয়।

## ৩.১৩ মুছে ফেলা ও ফেরত আনা

- **Delete:** প্রোফাইল ট্র্যাশে যায়। লগইন বন্ধ হয়, তালিকায় দেখা যায় না।
- **Restore:** ট্র্যাশ থেকে ফেরত আনে। ফিল্টারে "Trashed" বেছে দেখুন।
- **Force delete:** চিরতরে মুছে ফেলে। এটা আর ফেরত আনা যায় না।

**সতর্কতা:** শিক্ষার্থী চলে গেলে সাধারণত মুছে না ফেলে স্ট্যাটাস Transferred বা Dropped করুন, যাতে তার ইতিহাস, রেজাল্ট ও ফি-এর হিসাব থেকে যায়।

উত্তর: শিক্ষার্থীর ক্লাস বা গ্রুপে কোনো ঐচ্ছিক (Optional) বিষয় যোগ করা নেই। Classes → Edit → Subjects দেখুন।

**প্রশ্ন: Import-এ "class" ভুল বলছে।**
উত্তর: ক্লাসের নাম সিস্টেমে যেভাবে আছে হুবহু সেভাবে লিখুন (বড়-ছোট হাতের অক্ষর ও স্পেস সহ), অথবা ক্লাসের পেজ থেকে আপলোড করে class কলাম খালি রাখুন।

**প্রশ্ন: অভিভাবকের ফোন নম্বরের শুরুর ০ চলে যাচ্ছে।**
উত্তর: Excel-এ guardian_phone কলামের ফরম্যাট Text করুন।

**প্রশ্ন: প্রমোশনে New Roll খালি আসছে।**
উত্তর: ক্লাসের মূল (Main) পরীক্ষার Calculate Rankings করা হয়নি। আগে সেটা করুন অথবা রোল হাতে দিন।

**প্রশ্ন: শিক্ষকের ইমেইল দিলে "account আছে" বলছে।**
উত্তর: ইমেইলটি সিস্টেমে আগে থেকেই আছে। সেই অ্যাকাউন্টের সাথেই শিক্ষক প্রোফাইল যুক্ত হবে।
